What changes when a coach remembers

You stop repeating yourself, and the coach starts noticing patterns: the excuse you used last week, the goal you set a month ago, the thing that always trips you up at 4pm.

It follows up

Set a goal on Monday, get asked about it on Thursday. Mention a bad knee once, and it's never forgotten.

It's yours

Every memory is encrypted and stored in your own space on Walrus, a decentralized network. We don't keep a database of you.

It's transparent

Every reply shows which memories it used and, when it searched the web, which sources. You can see everything it knows about you.

Bring more than one part of your life

The coach gets better the more areas it knows about, because real life overlaps: bad sleep ruins training, stress at work turns into 4pm cake. Each area you talk about earns a badge.

How it works

You talk

Tell it what you're working on, in any language. It replies like a good coach: short, direct, one question at a time.

It learns

After each reply it extracts the durable facts — goals, schedule, constraints, progress — and stores each one encrypted on Walrus.

It recalls

Next time, your message is matched against your memories and the relevant ones shape the reply. No re-explaining.

Built for Walrus Session 8: Chatbots That Remember. Runs on an open-weight model (Qwen 3.8 27B via Groq) and Walrus Memory. It's a prototype: expect the occasional slow reply while a memory is being written.
